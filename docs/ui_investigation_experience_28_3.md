Calm의 행동 우선 구조를 production에 적용한다. 두 prototype의 합성 상태 버튼이나 예시 수치는 가져오지 않는다. 실제 결과와 분석 의미는 기존 API/SSE 계약을 그대로 사용한다.

## 첫 화면과 사용자 과업

1. 제목 한 줄과 설명 한 문장으로 보안 로그를 로컬에서 조사하는 도구임을 알린다.
2. 주 행동은 `예시 데이터로 둘러보기`, 보조 행동은 `내 로그 분석하기`로 둔다. 실제 파일 입력은 사용자가 선택하면 펼친다.
3. 결과가 침해·공격 성공의 확정이 아니라는 문장을 첫 화면에 둔다.
4. 지원 범위와 개인정보 세부는 접힌 안내에 둔다. 실제 파일을 선택할 때의 공개 서버 경고와 용량 제한은 입력 영역에 남긴다.
5. 결과는 확인할 사례·활동·관계·위험도 중 최대 네 수치로 시작하고, 사례 근거와 별도 기록은 사용자가 펼친다.
6. Live는 사람에게 이해되는 상태와 새 결과 행동을 먼저 보이고 관찰·관계·위험도·사례의 네 목록은 상세 안에서 확인한다. 사용자가 새 결과를 적용하면 그 상세를 연다. SSE 수신만으로는 펼치지 않는다.

검수 과업: 처음 보는 사용자가 30초 안에 목적을 설명하고, 예시와 실제 로그를 구분하며, 다음 행동을 찾고, 결과를 침해 확정으로 오해하지 않고, 연결 문제에서 복구 행동을 찾을 수 있는지 확인한다. 이는 다음 Safari 수동 검수에서 사용자에게 직접 물어볼 과업이다.

| 이전 문구 | 사용자 문구 | 내부 계약 |

| 합성 샘플 / 샘플로 체험하기 | 예시 데이터 / 예시 데이터로 둘러보기 | sample API 불변 |

| 게시 기록 / publication | 표시하지 않음 | status schema 불변 |
| epoch / projection | 표시하지 않음 | 분석과 복구 의미 불변 |

위험도가 낮아지거나 현재 결과와 더 이상 일치하지 않는 기록을 안전·해결로 표현하지 않는다. 원본 로그, IP, 계정, 경로와 query는 새로 표시하지 않는다. API/SSE, CSP, runtime 의존성, source checkout 경계는 유지한다.

## 자동 검사와 수동 검사

정적 계약, Node 동작, Chromium axe, 키보드, 폭과 시간대 결정성은 자동 검사한다. 실제 Safari의 키보드 사용, 200% 확대, 최소 창 너비, VoiceOver, 문구 이해도는 별도 수동 검수 전까지 NOT_TESTED이다. 자동 통과는 WCAG 2.2 AA 준수 선언이 아니다.
