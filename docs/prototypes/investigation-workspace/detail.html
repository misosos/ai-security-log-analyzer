값의 의미위험도는 기존 분석 결과, 확인 순서는 검토를 돕는 별도 제안, 로그 역할은 자료 종류입니다. 어느 항목도 공격 성공을 확정하지 않습니다.

핵심 요약

확인된 관찰과 분석상 연결

짧은 시간 동안 인증 실패가 반복된 뒤 성공 기록이 이어졌습니다. 이 조합은 추가 검토가 필요하지만, 정당한 사용자 활동인지 또는 침해가 있었는지는 이 자료만으로 알 수 없습니다.

위험도와 확인 순서는 서로 다른 값입니다. 확인 순서는 분석가가 검토할 순서를 돕는 참고 제안입니다.

먼저 확인할 내용

자료에서 아직 확인되지 않은 점

  • 로그인 주체가 정당한지
  • MFA 승인 주체와 사용 장치
  • 성공 기록 이후의 세션 활동

시간순 세부 기록은 에서 확인할 수 있습니다.

작업 1

자료 범위와 시간 경계 확인

수집된 자료가 해당 시간 범위를 충분히 포함하는지, 누락이나 지연 가능성이 있는지 확인하세요.

확인 방법

승인된 내부 분석 절차에서 자료 범위와 수집 상태를 비교합니다. 이 prototype은 명령을 실행하지 않습니다.

관련 근거

자료 범위를 확인하는 일반 조사 참고사항입니다. 이 검토 건의 사실이나 공격 증거가 아닙니다.

판단 근거와 한계

일반 참고자료와 사례에서 확인된 관찰은 서로 다릅니다.

참고 근거는 직접 증거가 아닙니다. 아래 자료는 일반적인 조사 방법과 한계를 설명합니다. 이 검토 건에서 공격이 발생했거나 성공했다는 증거가 아닙니다.
