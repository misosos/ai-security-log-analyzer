          해석과 개인정보 경계

          탐지는 침해 확정이 아닙니다. 상관관계는 인과관계가 아닙니다. 같은 IP가 같은 사람이나 공격자임을 뜻하지 않으며 NAT, 프록시, 공유 시스템일 수 있습니다.

          샘플 체험에는 사용자 로그를 업로드하지 않습니다. 실제 로그 입력은 loopback 연결에서만 처리합니다. 결과는 현재 탭 메모리에만 있고 새로고침하면 사라집니다. 원래 계정명, 원시 로그와 전체 쿼리는 화면에 표시하지 않습니다.

          로컬 업로드는 인증·방화벽·호스팅 보안의 대체 수단이 아닙니다. 인증 없는 공개 웹 업로드는 제공하지 않습니다. 개발 API 문서와 프로젝트 README에서 사용 범위를 확인하세요.
