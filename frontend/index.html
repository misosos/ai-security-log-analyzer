                  파일 선택과 분석 안내

                  직접 실행한 로컬 서버에서만 사용하세요. 공개 서버에는 민감한 로그를 업로드하지 마세요.

                  파일 업로드에서는 애플리케이션 인증·SSH 인증·웹 접근 로그 세 파일이 모두 필요합니다. 텍스트 직접 입력은 로그 종류 하나를 선택합니다.

                  이 분석은 외부 LLM을 호출하지 않으며 로그·결과·보고서를 서버에 영구 저장하지 않습니다. 비정상 종료 뒤 임시 파일이 남을 수 있습니다.

                  입력 방식
                  분석할 로그 선택 — 세 파일 모두 필수

                  시간, 인증 결과, 계정과 출발지 정보가 있는 UTF-8 텍스트 로그를 선택하세요.

                  시간과 SSH 인증 성공·실패가 기록된 UTF-8 텍스트 로그를 선택하세요.

                  시간, 요청, 응답 상태가 있는 UTF-8 웹 접근 로그를 선택하세요.

                  UTF-8 텍스트만 지원합니다(압축 파일 제외). 각 파일 32 KiB, 합계 80 KiB, 요청 전체 96 KiB 이하이며 한 줄 2048바이트·파일당 512줄 이하입니다.

                  로그 텍스트 직접 입력

                  최대 32 KiB, 512줄, 한 줄 최대 2048바이트입니다. JSON 요청 전체는 96 KiB 이하입니다. 서버에서도 다시 검증합니다.

                  0 / 32 KiB · 0 / 512줄

                  붙여넣은 로그는 사용자가 분석을 요청할 때 이 로컬 서버로 전송됩니다. 외부 서버로 보내지 않으며 브라우저 저장소에는 저장하지 않습니다. 실제 사용자 자료는 현재 검증 범위 밖입니다.

                  부분 입력 범위만 분석되며, 다른 로그나 시간대는 포함되지 않을 수 있습니다. 결과가 없다고 안전하다는 뜻은 아니며 탐지나 관계가 침해를 확정하지 않습니다.

                  직접 실행한 로컬 서버에서만 사용하세요. 공개 서버에는 민감한 Linux Audit 로그를 업로드하지 마세요.

                  UTF-8 Linux Audit 텍스트를 지원합니다. 실행 파일·인자·계정·경로 원문은 결과에 표시하지 않으며 외부 LLM도 호출하지 않습니다. 서버에 영구 저장하지 않지만 비정상 종료 후 임시 파일은 남을 수 있습니다.

                  이 결과는 Linux Audit 로그에서 검토할 프로세스 실행 관찰을 분류한 것입니다. 악성 행위나 침해 성공을 확정하지 않으며, 실행 목적과 승인 여부는 별도로 확인해야 합니다.

                  범주별 조사 후보

                  실행 결과와 해석 한계

                  성공은 실행 syscall의 기록된 결과를 뜻합니다. 파일 전송, 권한 변경 또는 공격 목적이 성공했다는 의미가 아닙니다.

                  지원 범위와 결과 안내

                  지원되는 관찰

                  Brute Force, Password Spraying-like, Path Traversal과 기존 분석에서 확인한 인증 관계를 다룹니다.

                  모든 로그 형식이나 공격을 지원하는 것은 아닙니다.

                  결과에서 볼 수 있는 것

                  위험도, 검토 건, 연결 근거와 추가 확인이 필요한 활동을 볼 수 있습니다.

                  검토 건의 상세 분석에서 활동 흐름과 확인할 작업을 살펴볼 수 있습니다.

                  분석 결과

                  예시 데이터 결과입니다. 실제 조직 환경이나 사용자의 보안 상태를 나타내지 않습니다.

                  텍스트 입력 분석 범위

                  한 종류의 입력 로그만 분석했습니다.

                  입력한 로그 범위에서만 분석한 결과입니다. 다른 로그나 누락된 시간대에 발생한 활동은 포함되지 않을 수 있습니다.

                  입력한 로그 종류는 사례의 검증된 역할과 다를 수 있습니다. 관계가 발견되지 않아도 공격 경로가 없다는 뜻은 아니며, 탐지 결과는 침해 확정이 아닙니다.

                  확인된 활동과 검토 건은 침해나 공격 성공의 확정이 아닙니다.

                  결과 요약

                  확인할 항목이 없습니다. 지원 범위나 입력 내용을 다시 확인해 주세요. 결과가 없다는 것은 안전을 뜻하지 않습니다.

                  검토 건

                  위험도는 기존 분석 결과입니다. 확인 순서와 로그 역할은 점검표를 요청하기 전까지 추정하지 않습니다.

                  추가 확인이 필요한 활동

                  다른 결과와 묶을 근거가 부족한 기록입니다. 중요하지 않거나 안전하다는 뜻은 아닙니다.

                  결과 해석 안내

                  탐지는 침해 확인이 아니며, 상관관계는 인과관계가 아닙니다. 로그인 성공도 공격 성공을 입증하지 않습니다. 조사 사례는 확정된 사고가 아닙니다.

                  기본 관찰 시각은 한국 표준시(KST, UTC+09:00)입니다. 상세에서는 UTC 시각도 확인할 수 있습니다.

                  해석과 개인정보 안내

                  탐지는 침해 확정이 아닙니다. 상관관계는 인과관계가 아닙니다. 같은 IP가 같은 사람이나 공격자임을 뜻하지 않으며 NAT, 프록시, 공유 시스템일 수 있습니다.

                  로컬 업로드는 인증·방화벽·호스팅 보안의 대체 수단이 아닙니다. 인증 없는 공개 웹 업로드는 제공하지 않습니다. 개발 API 문서와 프로젝트 README에서 사용 범위를 확인하세요.
